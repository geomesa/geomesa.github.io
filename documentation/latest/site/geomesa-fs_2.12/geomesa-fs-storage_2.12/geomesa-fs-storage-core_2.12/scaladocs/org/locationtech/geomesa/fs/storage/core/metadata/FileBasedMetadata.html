FileBasedMetadata 

Companion object FileBasedMetadata

class FileBasedMetadata extends StorageMetadata with CachedMetadata with LazyLogging

StorageMetadata implementation that stores all file information in a single JSON file. Uses HDFS lock files for cross-JVM write locking and synchronization for intra-JVM locking.
